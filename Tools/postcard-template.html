The stamp is built in — nothing to load. Pick a Frame only to override it with a different 1024×1044 overlay, which is then remembered in this browser until you Reset. Photos are downscaled to 2200px on the long edge before use, which keeps the export well under the size where the renderer starts to choke. Clean view hides these controls for a manual 1:1 screenshot. Everything runs locally — no network calls, nothing leaves the browser.

WebP is the default because that is what the site ships: the existing cards are 75–225KB each. PNG is there for when you want a lossless master to hand to something else. The file is named from the Name box, so typing postcard-ridge gets you postcard-ridge.webp ready to drop into Expect.Me.WWW/wwwroot/assets/images/.
