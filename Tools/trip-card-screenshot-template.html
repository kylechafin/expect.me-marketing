The Rangerly stamp is built in — nothing to load. Pick a Frame only to override it with a different 1080×1440 overlay, which is then remembered in this browser until you Reset. Photos are downscaled to 2200px on the long edge before use, which keeps the export well under the size where the renderer starts to choke. Clean view hides these controls for a manual 1:1 screenshot. You can preset text and state via URL: ?theme=warning&text=Your%20trip%20text (states: resting, warning, late). Everything runs locally — no network calls, nothing leaves the browser.

Face takes a Plus Jakarta Sans .woff2 and embeds it, so the export matches the app rather than falling back to Arial. Use the variable file: the buttons are set at 700, and the face is declared across the whole 100–900 range so those axes resolve. A single static weight is declared across that same range, which means it answers every weight with itself — the buttons come out regular rather than bold, and nothing warns you. Remembered like the frame is. The app loads the same face from Google Fonts in App.razor, but a linked font cannot work here — the exporter draws into an SVG that fetches nothing.

Card scale is one app rem in poster pixels. Every figure in the card is written against it, so 16 is the app at 1:1 and 36 is the blow-up this canvas wants; nothing drifts out of proportion in between.
